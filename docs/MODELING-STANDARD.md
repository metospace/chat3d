# 通用建模标准

本标准用于直接生成与 Blender 生成的建模目标和结果判断，适用于物件、产品、家具、织物、人物、动物、植物、地形、建筑、车辆、装配体及完整场景。默认目标是比例可信、结构完整、材质有依据、适合目标视图的精细模型，不默认玩具化、卡通化或基本体拼装。它是质量约束，不是照片级还原、工程可制造性或模型服务必定成功的保证。

本轮参考 img2threejs 和 Yuki3d 技能思路新增的参考像素对照、独立形体门禁及强制 GLB 回读已撤回，恢复原有生成与检查链路；六项自检及明确缺陷修复仍保留。

## 1. 优先级与适用范围

1. 用户明确的尺寸、数量、参考图、风格、颜色、保留项与修改范围优先。用户要求卡通、低模、抽象或指定艺术风格时遵从该风格，但仍保留约定的比例语言、必要特征、连续形体、合理关系与材质一致性；不能借风格化省略明确要求。
2. 没有明确风格时，以现实对象的形态和材料逻辑为基准。不默认圆胖比例、统一大倒角、悬空肢体、塑料高光、统一蓝灰配色或随机装饰。参考本身是风格化作品时，按参考表达，不擅自改为写实照片风格。
3. 仅对本次新增或明确修改的内容应用标准。保持既有资产、用户手改、布局、比例、材质、动画、连接及局部风格；已有目录或资产名称含“精细”不等于已经合格，也不构成自动替换的授权。
4. 下文类别规则按当前对象的实际构成选择。例如木椅涉及家具与木材，不因此需要人物、植物、车辆或建筑；空置场景不自动补人，独立物件不自动补背景。六项通用标准始终适用，但不适用的具体子项应说明原因，不虚构需求。
5. 缺少不可替代的尺寸、参考或实现能力时，说明已知事实、假设和限制。可保留实际完成的阶段草稿，但必要特征未实现时就是未完成，不得用文字说明、名称、贴片或占位件冒充已建成。

## 2. 构建顺序与细节分配

按以下依赖顺序构建和修正，后级不能掩盖前级问题：

1. **整体剪影与比例**：对象身份、总尺度、姿态、主轴和整体重心；参考中的长宽高关系及主轮廓。
2. **次级体积与负空间**：主体分区、肩腰腹或壳体过渡、凹陷、镂空、窗洞、肢体间隙、枝叶层次；不能以完整实心块替代决定身份的空腔。
3. **结构、解剖或植物关系**：支承、关节、装配、受力趋势、肢体连接、生长方向等。连续有机表面要连贯，独立部件要合理分离并正确接触。
4. **材质与表面分区**：材料类别、颜色、粗糙度、金属/涂层/透射、纹理方向与尺度，保留对象真实的软硬差别。
5. **相关精细特征**：目标画面实际看得见、对身份或用途有贡献的边缘、缝线、五官、叶脉、纹理等。不是把整场所有表面无限细化。

按对象在目标画面中的投影尺寸和观察距离分为三级分配，不设跨类别统一面数、部件数或固定“每物件若干细节”的门槛：

| 层级 | 判断依据 | 需要表达 | 不应做 |
| --- | --- | --- | --- |
| 整体级 | 缩小到目标全景后仍决定辨识的轮廓、姿态、色块或空间关系 | 主次体积、关键负空间、主材质、落地与组合关系 | 用纹理补救错比例；远景对象仍逐个堆微小零件 |
| 结构级 | 正常查看目标对象时能分辨的分区和部位 | 关节、门窗、座背、衣褶大走势、枝干分叉、车轮轮拱、可见接缝等适用特征 | 以无关附属物增加“丰富度”；所有形状都套同一圆角 |
| 近景级 | 约定近景确实可见，或用户明确要求 | 尺度适当的缝线、边缘过渡、表面微结构、可辨识标识等 | 全局加密、全局噪声、虚构不可读文字或无依据内部机构 |

参考全景、对象视图和必要局部的屏幕占比应可比较。特征若在目标输出中已不可辨识，优先维持轮廓和稳定渲染，而非继续增加几何；用户明确要求的特征不能仅因默认观察距离而删掉。小物件近拍也可能需要高细节，大场景远处主体不必与前景同等精度。

生成只采用一个高质量标准，生成方式只有“直接生成”和“Blender 生成”，不提供快速、普通或精细质量档位。两种方式都应完整落实明确需求、可信主形、必要结构、材料差异和相关近景细节，不接受玩具式占位完成。细节投入取决于对象、用户目标和实际画面，不是质量降档；复核按明确差异推进，不无限润色。时间或资源不足时保留未完成项和可继续草稿，不把质量标准降低为“普通质量”，也不承诺固定耗时。

旧配置中的 `generationQuality`、`generationStyle` 和 `style` 在加载时移除并重存，不改变模型地址、模型、推理参数、任务预算或流式设置；API 密钥仍只在用户明确同意记住时持久保存。风格由当前用户要求和参考确定，不再由旧质量或风格偏好暗中覆盖。视口“显示质量”只影响实时渲染性能，不是生成质量档位。

## 3. 几何、边缘与关系

- 选用适合对象的剖面、旋转体、曲线扫掠或网格表达。基本体适合真实的基本形状，也可作为中间剪影；连续外壳、肌体、布面、地貌不能把球体、盒子或胶囊堆叠后直接称为完成。
- 曲面要有连续、稳定的轮廓和法线。平滑着色不能修复断开的体积、突兀接头或错误解剖；细分不能自动修复拓扑。保留设计上的折线、硬边和材料交界，不把一切平滑成软塑料。
- 边缘锐利程度由对象尺度、材料、工艺、磨损状态和参考决定：切削金属、折弯钣金、玻璃、石块、木材、皮肤与织物不是同一种倒角。不要统一毫米级倒角、统一厚圆边或统一零锐边。
- 需要实体厚度的壳口、板材、杯沿、座垫、可见玻璃边和开孔内壁应表达厚度，比例由参考和材料决定，不套通用数值。叶片、布片、纸张等很薄的对象可按视距采用薄面；不能把有意的薄面或开口一律判坏，也不能在可见边缘暴露明显零厚度而不处理。
- 相接部位核对接合位置、方向和可见间隙；支脚、轮胎、肢体、枝干、家具连接、墙与楼板均按对象检查。避免悬空、穿插、共面闪烁、错位和不合理挤压；有依据的生长穿合、榫接、遮挡或柔性变形不应机械地当作错误。
- 接触点和连接元数据只是检查辅助，不能代替可见接合面。人物握持要看腕掌连续、拇指与四指、包握或单指按压、工具朝向与穿插；登记接触合格不代表手型合理。现有人物检查仍要求当前版本手部与工具的两个局部视角，不能用全身图或接触点替代。
- 装配和场景关系只检查本次对象及其受影响邻接关系，不擅自拆解隐藏结构、增加生产机构、改变无关对象或建立额外审计流程。

## 4. 按类别选择的形态规则

下表是条件规则，不是每次任务都要填满的新增清单。复杂对象可跨行，例如带软包的椅子同时涉及家具与织物；只采用实际相关项。

| 对象 | 核心关系与应有表达 | 常见错误 |
| --- | --- | --- |
| 普通物件与产品 | 识别性轮廓、截面变化、主次壳体、握持/开合/使用部位；有参考的开口、内壁、分缝与附件位置 | 统一圆盒加标签；孔洞用黑片假装；所有产品像塑料玩具 |
| 家具 | 座背与支腿比例、承重路径、落地、板厚/软包厚度、接合与必要活动空间；木纹方向与构件逻辑相符 | 支腿插错面、座面悬空；硬木和软垫同一圆角与材质 |
| 织物与软体 | 整体垂坠、张力与压缩区、主要褶皱流向、接触与厚薄；缝线只在可见且有依据处补充 | 随机皱纹覆盖受力错误；每条褶皱变成独立硬管；织纹放大到像沟槽 |
| 人物 | 参考或设定中的身段、头颈肩躯干与四肢比例，肘腕膝踝连续、姿态重心、衣服包裹体积；可见五官与手足按观察尺度表达 | 椭球头和悬空胶囊肢体；肩腕断裂；手掌粘在工具旁却没有握持 |
| 动物 | 物种体型、躯干与颈头比例、肢体关节和步态、足/蹄/爪接地、尾翼鳍等实际结构；毛羽先大体积与流向再微表面 | 把人类关节套给四足；尾翼随意插接；靠毛纹掩盖错误骨架与轮廓 |
| 植物 | 物种或参考中的主干、分枝层级、节间、叶序、叶片/花果尺度与朝向，冠层疏密与负空间；需要时表达根基与土壤关系 | 球冠加直杆；所有叶片等大等向；枝条不接主干；不分物种乱加花果 |
| 地形与自然物 | 大地势与坡向、山脊/沟谷/水岸的连续关系、岩块分层与尺度、地表覆盖及相邻地物接触 | 随机噪声当作地貌；水面爬坡；高频凹凸掩盖地势错误 |
| 建筑与室内 | 体量、层高与开间关系、墙/屋面/楼板、门窗洞口及深度、适用的结构支承与通行空间；风格和细部以参考为准 | 贴窗代替关键洞口；屋面和墙断开；门窗比例或通行关系不成立 |
| 车辆 | 车身姿态、轴距轮距与轮径关系、驾驶舱/乘员舱、轮拱与转向/连接部位、可见车灯玻璃与面板分区；不同交通工具按自身结构判断 | 轮子与地面分离；车体穿轮；把汽车结构强加给船、飞机或轨道车辆 |
| 装配体 | 构件接口、父子层级、轴线、配合间隙、支承和用户指定的运动关系；重复件一致且数量正确 | 孤立零件拼成外观却没有接口；全局缩放导致接口错位；演示运动冒充物理仿真 |
| 完整场景 | 主次对象、统一尺度与风格、布局、支承、朝向、必要交互与通行；细节按镜头和对象重要性分配 | 堆物件冒充完整；前后景精度失衡；添加未要求的人、环境或生产流程 |

## 5. 材质、微表面与输出保真

- **介电材料**：皮肤、木材、织物、橡胶、塑料、陶瓷、混凝土和普通漆面通常按非金属处理；用正确颜色、粗糙度与适用纹理表达差异，而不是一律高亮或靠提高金属度变“高级”。特殊材料以实际参考为准。
- **金属**：裸金属与其氧化、涂覆区域分开判断。喷漆金属不能因为内部基材是金属就把整个漆面设为裸金属；可用受支持的涂层参数表达清漆，不滥用涂层使皮肤、布料和木材都像塑料。
- **透射与透明**：玻璃、透明塑料、水体等根据实际用途选择透射、折射率、厚度和粗糙度；不能仅靠统一降低不透明度模拟全部透明物，也不承诺当前查看器没有实现的焦散或彩色透射阴影。
- **几何与微表面分工**：影响轮廓、遮挡、开口或明显投影的特征用实际几何；毛孔、细织纹、微小拉丝、细颗粒等通常由尺度适当的法线/粗糙度表达。近景确实需要几何时按需处理，不把每个毛孔、纤维或砂粒都变成网格。
- 纹理要检查 UV 存在性、塌缩、拉伸、接缝、方向和密度，文字不能无意镜像；法线方向、硬软边、切线及正负凹凸关系要正确。无贴图对象不为通过清单强加 UV 或纹理；已有贴图不能被错误投影破坏。
- 颜色贴图与数据贴图区分色彩空间。Blender 中颜色通常为 sRGB，法线、粗糙度等为 Non-Color；需要随 GLB 交付的程序材质应转换为当前支持的参数或兼容贴图。原生节点外观不等于导出后必然相同。
- 新产品、洁净室、健康皮肤或用户指定的干净外观可保持干净。不强加噪声、污渍、锈蚀、划痕和做旧，不编造不可辨识商标文字；有参考和需求时再表达磨损的位置、方向和尺度。
- 灯光和背景用于看清形体与材质，不以过曝、暗部遮挡、景深或夸张反射隐藏缺陷。相同模型在不同渲染器、环境光和色调映射下可能有差异，不能据一次好看的棚拍图宣称所有输出一致。

## 6. 可复核的六项判据

沿用 `src/domain/detailAcceptance.ts` 的六个键，不增加真实感总分、自动照片级认证或参考相似度保证。复核针对当前版本、真实对象和已实际送达的图像；明确尺寸沿用现有需求容差，透视缩短不能当真实尺寸。

| 键 | 可观察与可记录的判据 | 不通过或未完成的条件 |
| --- | --- | --- |
| `silhouette` 外形与比例 | 全体入画且轮廓可辨；对比总长宽高及主要部位比值、主轴、姿态、负空间位置；明确数量和尺寸能对应实际对象 | 关键比值或剪影明显偏离；仅靠颜色/名称辨认；必要视角被裁切而无法判断 |
| `structure` 功能结构 | 按身份核对主要分区、开口/厚度、解剖连接或分枝层级；明确要求的特征逐一对应真实几何 | 黑片假孔、缺主结构、断裂有机体、仍是占位外壳；功能或结构关系只有文字没有模型 |
| `connections` 连接与接触 | 在看得清接口的视角检查接合面、支承、关节、肢体/枝干连续性；用上下文判断人、工具和操作面；已登记连接不得分离 | 悬空、穿插、接触点不在真实表面、握持不合理；缺必要上下文或手部证据则待核对 |
| `materials` 材质与表面 | 真实渲染中能区分适用材料；粗糙度、涂层、透射、纹理尺度和方向有依据；已用贴图的 UV 与法线有效 | 软件几何图冒充材质验收；塌缩 UV、错误法线、错材料；强光或噪声掩盖缺陷 |
| `details` 用途相关细节 | 在目标画面或约定近景核对必要特征的有无、位置、方向及尺度；简单实体也核对边缘、比例与表面 | 缺明确特征；无关装饰替代细节；只有增加零件数/面数的陈述，或依赖不可见内容宣称完成 |
| `context` 完整性与环境关系 | 独立物件在范围内完整；场景中的数量、尺度、落地、朝向、活动/通行空间与相邻对象一致；无关内容保留 | 整体缺件、落地错误、相互阻塞；局部改动破坏既有资产、风格或布局；未经允许扩展环境 |

结论语义：`pass` 是已有证据支持的当前项模型自检通过，不是用户或工程认证；`fail` 是有明确缺陷；`unknown` 是证据或能力不足；`not_applicable` 只用于确实不适用且守卫允许的项。外形与用途相关细节不能跳过，简单实体也有其应检查的边缘、比例和表面。已有失败不因版本增长、导出成功或少拍一个视角自动消失。

## 7. 取景、证据与缺陷修复

先用能看清整体的画面定位差异，再检查受影响部位。相机和焦距应服务于判断：比例宜用不夸张的透视或适用的正交视图；接合、手部、洞口与材质需能看清相关细节；场景关系保留必要上下文。不要自动要求所有类别、所有对象固定四视图或逐项无限取图。角度选择和截图数量遵守当前链路已有规则与预算。

参考图是形态依据，不是生成结果的验收证据。只有实际返回并送达模型、版本和范围相符的生成图可支持相应判断；归档存在不等于看过。局部或隔离图不能证明画面外关系，软件几何图不能证明 PBR 材质，单张 Blender PNG 只能说明该图可见范围。未见背面、被遮挡结构和无尺度依据尺寸标为假设或待核对，不编造观察；需要的真实图不可用时保留未完成，不以文字自评冒充看图。

修复应改变真实几何、变换或材质，再按问题复查；不是只改结论、加标签或重拍更讨巧的角度。以下例子展示跨类别的可执行差异记录，不是要求每个任务新增这些对象：

| 可见缺陷 | 实际修复 | 适当复查 |
| --- | --- | --- |
| 产品把手镂空被实心体封住 | 修改截面或网格，恢复孔洞和适用内壁，保留正确外轮廓 | 对应参考方向与能见孔深的斜视图 |
| 椅腿悬空、软垫像硬盒 | 修正腿长/接合及落地；调整垫体受压轮廓与材质，不统一放大倒角 | 全体侧斜视与座腿接合局部 |
| 衣褶杂乱，人物腕掌断开或工具穿手 | 先修连续体积、姿态和接触，再整理受力褶皱与相关手型 | 全身姿态及现有规则要求的两个手部/工具局部视角 |
| 动物后肢关节方向不合物种、足底离地 | 修正肢体链、肌体连接和接地，不靠毛发纹理遮挡 | 侧视轮廓与足部/躯干关系 |
| 树冠像球，枝叶漂浮 | 调整主枝分叉、冠层层级和负空间，把相关叶簇接回枝系 | 全冠轮廓与可见分枝局部 |
| 地形噪声很密但河道向上爬坡 | 先修大地势、河谷与水面关系，再控制地表纹理尺度 | 全局斜视与沿河道的高程关系 |
| 建筑窗是黑片，车辆车轮穿过轮拱 | 分别补必要洞口深度/窗层关系，或修正轮轴与轮拱相对位置 | 建筑立面斜视，或车辆侧视及轮拱局部 |
| 装配轴线错位、场景对象比例冲突 | 局部修正接口坐标或明确错误对象的尺度，保留无关资产和布局 | 接口局部与必要场景上下文 |
| 金属漆面像铬，木纹拉伸或皮肤毛孔像坑洞 | 修正介电/金属/涂层参数、UV 与纹理尺度/强度，不新增无关几何 | 能辨材料且不过曝的当前渲染局部 |

## 8. 现有链路与能力边界

- 通用建模提示核心位于 `src/ai/generationStyle.ts`，直接生成使用直接链路说明，`src/ai/blenderSkill.ts` 在相同核心上补充 bpy、材质与导出相关要求；专题规则仅在当前任务涉及时生效。文档是说明，不是新增的运行时工具、预设或自动审计器。
- 直接生成主提示、参考图的剪影/细化流程及隔离组件提示均按实际类别组织。工艺顺序、操作人员、工位、物料和净空只用于相关任务；人物、动物、植物、建筑或独立物件不因沿用场景工具而被强加工业结构或配套。
- **直接生成**使用现有 Three.js 几何、参数化程序、命令和可编辑网格链路；连续建模保留当前数据守卫、取景、缺陷修复、六项自检和草稿确认。未检查项保持待核对；单次兼容和隔离数据生成不因此获得多轮视觉验收能力。具体实现限制见[写实生成与实时渲染](REALISTIC-MODELING.md)。
- **Blender 生成**在本机 Blender 内执行脚本、渲染并导出同版 BLEND、GLB、PNG。桌面端使用用户本次会话授权的原生执行链路，不需要另开 Node 服务；Web 使用明确启用的本地适配器。生成后 PNG 返回模型，后续轮次记录观察，明确缺陷用脚本局部补丁修复并重新渲染；这不是额外调用直接生成，也不运行其完整六项提交守卫。单图已复核不等于未见部分或工程质量通过。
- Blender 字面补丁保留未改源码，但每次在空工程执行完整脚本，不是持久会话或几何隔离，也不自动包含工作台手动修改；随机/时间相关脚本可能改变无关结果，不能声称绝对保留。GLB 不支持任意 Blender 节点效果，原生工程、导出网格和主画布预览的能力不同。
- 本标准不新增骨骼蒙皮、物理、毛发系统、专业 UV 展开、任意着色器、外部模型/纹理服务、第三方质检或隐藏结构生成能力。已有工具能够实现的目标必须落实为实际数据；当前链路不能实现的必要要求须明确说明并保留未完成，不能以标准写了就视为已支持。
- 时间、轮数、Token、几何/存储/截图预算、范围与位置锁、动画关系保护、执行授权及用户确认保持不变。资源不足可以如实交付可继续的阶段草稿，不得静默删特征、降低质量标准、无限审查或以高质量要求作为越权依据。


## 9. 回归验证边界

`tests/generation-method-picker.mjs` 覆盖两种生成方式切换、执行中锁定、新项目独立选择及旧配置迁移；沿用设置界面测试的无动画 ConfigProvider，避免 jsdom 将弹层退场动画当作仍打开的菜单。`tests/generation-quality.mjs` 覆盖旧质量值不能减少复核、真实图片需后续轮次判读、预算上限以及单次兼容请求保留用户风格。测试使用固定模型回复与图片，只验证执行规则，不代表真实模型生成质量。

标准、PBR 参数和测试通过都不保证每次生成质量。最终判断只基于当前实际结果、有效证据、用户要求和清楚表达的未完成项，不产生虚构的照片级评分或质量承诺。
