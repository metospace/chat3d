# 写实生成与实时渲染

这条路径使用现有 Three.js，不需要安装 Blender，也不访问外部纹理服务。

- 在生成档位菜单中分别选择细节档位（快速 / 精细）与生成风格（写实 / 简洁）。缺省风格为写实；用户指令与参考图优先。
- 风格在任务开始时随配置传入单次生成、Pi agent 和隔离组件生成，影响后续新增或明确要求修改的内容，不会重塑已有模型。
- 写实规则强调比例、连续轮廓、板厚、装配接缝、尺度合理的倒角及材料区别。已有资产仍需检查实际质量；目录名称和零件数不等于写实质量。
- 视口的“显示 → 灯光效果”可切换写实棚拍与经典展示，选择保存在本机。灯光不会写入模型材质，也不会重建场景。
- 新增的默认喷漆、裸金属、玻璃与工装材质使用不同的物理参数。程序纹理是本地生成的细微法线与粗糙度变化；已有项目中同名材质保持原值。

项目 JSON、局部外观修改、GLB 导入导出和离线 HTML 支持 `clearcoat`、`clearcoatRoughness`、`transmission`、`thickness`、`ior` 五个物理材质参数。厚度单位为米。GLB 中高级材质扩展的额外贴图仍需先转换为当前支持的标准贴图，不代表支持任意 Blender 节点材质。透射玻璃不参与不透明对象的实例合批，也不投射实心黑影；当前没有模拟玻璃焦散或彩色透射阴影。

离线 HTML 内嵌室内环境生成器与导出时选择的灯光参数，支持环境反射和阴影，无需加载远程资源。GLB 保留模型与材质，查看器自身的灯光与色调映射会影响最终观感。

## 参数化构建流程

Pi 连续建模新增 `build_modeling_program` 和 `read_modeling_program`。参考图任务默认可编写 Three.js 函数体，运行时提供 `THREE`，返回命名 Group/Object3D；曲线 Shape、ExtrudeGeometry、BufferGeometry、管线及 PBR 材质直接转换为独立可编辑网格，不执行外部文件或导出脚本。源码保存在项目节点元数据，不会在打开项目时自动执行，也不会自动反映后续手动编辑。

执行使用无同源权限的 sandbox iframe 与独立 Worker，CSP 禁止网络，15 秒超时与取消会终止 Worker 并清理资源。单次最多 1000 网格、100 种材质、50 万顶点，结果还须满足现有项目存储预算；骨骼、实例、外部贴图与自定义着色器明确拒绝，不静默丢失。脚本只接收本次源码和 Three.js，不接收模型密钥、项目数据或聊天。

构建完成仍走原有草稿、编辑范围、尺寸与真实截图复核。先构建主轮廓再看图修正，后补用途细节；绑定仅表示实际部件存在。整体重建必须明确组件 ID，并原子替换；带动画、连接、关节或资产关联的组件须使用保留节点的局部编辑，禁止整体重建丢失关系。局部选区与位置锁不会因脚本放宽。

参数化构建必须明确stage：silhouette是同一任务的中间剪影，不能直接提交完成；detailed要求完整方案的全部特征关联到实际返回部件，仍不证明视觉质量。剪影之后必须继续补功能机构、连接、操作界面和表面分区，不能因提速只交主体框架。已有旧项目没有阶段字段时保留原语义，不按部件数量猜测阶段。

### 源码和复核提速

`read_modeling_program` 使用互斥selection：`{mode:'summary'}`目录、`{mode:'lines',start:1,end:24}`行、`{mode:'characters',start:0,end:3993}`字符、`{mode:'search',query:'函数名'}`搜索。不能混用多个模式或复制返回window元数据作为参数。nextChar只作为characters.start或search.start续读。结束范围超过末尾会截到实际内容，单页最多120行/12000字符；错误给出简短有效边界和合法重试示例。`patch_modeling_program` 仍拒绝过期、歧义、交叠、无变化及越权重建。

工具组使用groups数组一次启用，disableGroups收回不再需要的参数；核心取景与脚本工具无需额外启用。所有取景回执携带reviewReadiness，列出真实组件/部件引用、当前视角和提交范围，便于下一轮合并细节与整体复核。不可用、过期或同轮证据仍不能通过，未知与实际缺陷不能被清空。上下文只删除被替代的同版本视角，不删除原参考图或不同视角的有效证据。
复核可按标准分次补齐，同一组件当前版本的有效结论合并，未提交项保持unknown而非通过；已知fail保留。补充不绕过真实证据、节点引用、隔离关系和软件材质限制。底层完整复核验证仍要求六项，不完整直接调用会明确列出缺项。

这些机制减少重复传输与协议往返；未进行同提示词付费模型计时对照，不承诺固定提速比例。主体比例、外壳曲率与操作件层次先于微细字标完成，不以细分数和零件数代替质量。


验证：`node tests/modeling-program.mjs`、`node tests/modeling-program-draft.mjs`；真实浏览器隔离检查使用 `node tests/modeling-program-browser.mjs`。本次以用户提供的 Codex 原始参数化源码验证 641 个可编辑部件、24864 个三角面、14 种材质及离线 HTML；这是源码执行与保真链路验证，不是重新调用模型看同一参考图生成的质量成绩。
